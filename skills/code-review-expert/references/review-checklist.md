# 代码审查检查清单

## 安全

- 密码必须使用现代 KDF 与独立随机盐进行哈希存储。
- 严禁以明文形式存储或记录密码。
- Token 必须具备随机性、唯一性、过期机制，并在登出后失效。
- 必须通过查询条件阻断跨用户数据访问。

## 数据层

- 数据库迁移需要兼容已有数据库文件。
- 新增约束与索引需匹配实际查询模式。
- SQL 必须使用参数化查询。

## 行为正确性

- 认证失败时不泄露敏感信息。
- 未授权操作必须安全失败。
- 鉴权接入后原有功能仍应保持可用。

## 测试

- 覆盖注册/登录/登出流程。
- 覆盖多用户数据隔离。
- 覆盖错误凭据与越权访问等负向场景。
